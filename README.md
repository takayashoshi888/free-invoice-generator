# Free Invoice Generator · 免費請求書產生器

一款**免費、純前端、無需註冊**的日式請求書（發票）產生器。填入資料、上傳印章，一鍵匯出 PDF，所有資料僅存於你的本機瀏覽器，不上傳任何伺服器。

> 品牌標誌：金線鳥居（torii）+ `Free Invoice / GENERATOR`。

---

## ✨ 功能特色

- **日式請求書範本**：發票番號、發行日（西曆／令和切換）、宛名、件名、明細表、消費稅、振込先（多組銀行帳戶）、公司角印等一應俱全。
- **即時預覽（所見即所得）**：左側表單、右側 A4 預覽，修改即時反映。
- **一鍵匯出 PDF**：使用 `html2canvas` + `jsPDF` 將發票匯出為 PDF；亦支援直接列印。
- **印章 / Logo 上傳**：可上傳公司 Logo、公司角印（方印）、個人印鑑；**未上傳時自動隱藏佔位圖**，個人使用者畫面更乾淨。
- **印章產生器入口**：功能欄（toolbar）與首頁導覽列提供「🔏 印章產生器」按鈕，連往線上印章產生工具 <https://sealkit.app/kaishain>（另開新視窗）；應用頁的印章上傳區塊亦附情境提示，方便尚未有印章圖檔者先製作再上傳。
- **草稿自動保存**：最近 10 筆草稿存於 `localStorage`，隨時續編。
- **雙語介面（中文 / 日本語）**：右上角 🌐 小地球切換語言，選擇記住於本機。
- **完美行動端適配**：採用「容器寬度測量 + class 切換」的回流（reflow）方案，手機上單列堆疊、字級適中，文字清晰可讀（非縮放，避免逐字換行）。
- **返回主頁**：應用頁 toolbar 提供「← 返回主頁」按鈕，方便回到落地頁。
- **隱私優先**：無帳號、無後端、無資料上傳。

## 🛠 技術架構

- **純靜態單檔 HTML + 原生 JavaScript**，無建置步驟、無後端、無套件安裝。
- 第三方函式庫（CDN）：`html2canvas`、`jsPDF`、`Noto Sans JP`（字型）。
- 資料持久化：`localStorage`（草稿、語言偏好）。

## 🚀 使用方法

1. 用瀏覽器直接開啟 `index.html` 進入首頁，點擊「免費開始使用」前往 `seikyusho.html`。
2. 於應用頁填寫發票資料，右側即時預覽。
3. 點擊 **PDF下載** 匯出 PDF；**列印** 直接列印；**儲存草稿** 存到本機。
4. 切換語言：點擊右上角 🌐 小地球，選擇 中文 / 日本語。
5. 返回首頁：應用頁 toolbar 點擊 **← 返回主頁**。
6. 印章產生器：點擊功能欄或首頁的 **🔏 印章產生器**（或印章上傳區的提示連結），前往 <https://sealkit.app/kaishain> 製作印章圖檔，下載後回到本頁「上傳」即可。
