# Free Invoice Generator · 免費請求書產生器

一款**免費、純前端、無需註冊**的日式請求書（發票）產生器。填入資料、上傳印章，一鍵匯出 PDF，所有資料僅存於你的本機瀏覽器，不上傳任何伺服器。

> 品牌標誌：金線鳥居（torii）+ `Free Invoice / GENERATOR`。

> 📋 專案維護與交接說明（變更記錄、部署、環境注意事項）見 [HANDOFF.md](./HANDOFF.md)。

---

## ✨ 功能特色

- **日式請求書範本**：發票番號、發行日（西曆／令和切換）、宛名、件名、明細表、消費稅、振込先（多組銀行帳戶）、公司角印等一應俱全。
- **即時預覽（所見即所得）**：左側表單、右側 A4 預覽，修改即時反映。
- **一鍵匯出 PDF**：使用 `html2canvas` + `jsPDF` 將發票匯出為 PDF；亦支援直接列印。
  - 匯出時一律以 **A4 版面（794×1123 px）** 重新渲染，因此**電腦與手機產出的 PDF 完全一致**，行動端不再因為預覽的窄版面回流而被裁掉一半內容。
  - 內容量超出一頁時自動處理：輕微溢出會等比微縮至單頁；明顯超過一頁（大量明細）則自動分成多張 A4，內容不會被截斷。
  - 已針對 iOS Safari 強化：字型載入等待、圖片解碼等待、canvas 面積上限保護、連點防護。
- **印章 / Logo 上傳**：可上傳公司 Logo、公司角印（方印）、個人印鑑；**未上傳時自動隱藏佔位圖**，個人使用者畫面更乾淨。
- **印章產生器入口**：功能欄（toolbar）與首頁導覽列提供「🔏 印章產生器」按鈕，連往線上印章產生工具 <https://sealkit.app/kaishain>（另開新視窗）；應用頁的印章上傳區塊亦附情境提示，方便尚未有印章圖檔者先製作再上傳。
- **草稿自動保存**：最近 10 筆草稿存於 `localStorage`，隨時續編。
- **雙語介面（中文 / 日本語）**：右上角 🌐 小地球切換語言，選擇記住於本機。
- **六種主題可切換（首頁）**：右上角 🎨 選單提供 6 種配色，選擇記住於本機（`fig_theme`），重新載入不閃白：
  | 主題 | 定位 |
  |---|---|
  | 原版（預設） | 深藍 + 紫青漸層，活潑科技感 |
  | A. 黑白正式 | 純白紙張 + 黑墨 + 細灰規線，最正式的公文感 |
  | B. 藍色商務 | 企業藍 + 天空藍，沉穩可信 |
  | C. 灰色極簡 | 中性灰、去裝飾，內容優先 |
  | D. 黑金品牌 | 近黑底 + 品牌金 `#D4AF37`，與品牌標誌一致 |
  | E. 橘黃 | 暖橘 + 琥珀，親和明亮 |
  - 所有顏色集中為 CSS 變數，切換 `<html data-theme="...">` 即可換版，不影響版面結構。
  - 全數文字／背景組合已達 **WCAG AA（4.5:1）** 對比度。
- **五種主題可切換（應用頁）**：toolbar 的 🎨 選單提供 5 種介面配色（原版、黑白正式、藍色商務、灰色極簡、橘黃），與首頁共用同一份 `fig_theme` 偏好。
  - **只換介面，不換請求書**：A4 請求書本體（白紙、黑墨、深藍表頭、紅色印章）恆定不變，因此 **PDF 匯出／列印結果與主題無關**，正式送出不受影響。
  - 首頁的「黑金品牌」為深色版，應用頁不提供；若偏好為 `gold` 會自動回落到原版。
  - 機制：A4 本體使用 `--doc-*` 令牌（永不隨主題變動），介面使用 `--ui-*` 令牌（隨主題變動），兩套命名空間互相隔離。
- **明細表頭顏色可選（5 色）**：應用頁「明細」表格正上方提供「明細表頭顏色」——原版深藍 / 藍色 / 黑色 / 灰色 / 橘黃。
  - 這是**文件級**設定：只改變請求書「明細」表格的表頭底色，會存入草稿、並反映在 PDF 與列印結果。
  - 與介面主題**完全獨立**：切換介面主題不會改變表頭色，反之亦然（兩者經交叉驗證互不干擾）。
  - 5 色表頭上的白色文字皆達 WCAG AA（最低 5.18:1）。
- **完美行動端適配**：採用「容器寬度測量 + class 切換」的回流（reflow）方案，手機上單列堆疊、字級適中，文字清晰可讀（非縮放，避免逐字換行）。**預覽**採行動端回流版面；**PDF 匯出**則固定使用 A4 版面，兩者互不影響。
- **返回主頁**：應用頁 toolbar 提供「← 返回主頁」按鈕，方便回到落地頁。
- **隱私優先**：無帳號、無後端、無資料上傳。

## 🛠 技術架構

- **純靜態單檔 HTML + 原生 JavaScript**，無建置步驟、無後端、無套件安裝。
- 第三方函式庫（CDN）：`html2canvas`、`jsPDF`、`Noto Sans JP`（字型）。
- 資料持久化：`localStorage`（草稿 `seikyusho_drafts_v1`、語言 `fig_lang`、主題 `fig_theme`；主題偏好由首頁與應用頁共用）。

## 🚀 使用方法

1. 用瀏覽器直接開啟 `index.html` 進入首頁，點擊「免費開始使用」前往 `seikyusho.html`。
2. 於應用頁填寫發票資料，右側即時預覽。
3. 點擊 **PDF下載** 匯出 PDF；**列印** 直接列印；**儲存草稿** 存到本機。
4. 切換語言：點擊右上角 🌐 小地球，選擇 中文 / 日本語。
5. 切換主題：點擊右上角 🎨，首頁可選 6 種配色、應用頁可選 5 種；偏好共用並記住於本機（應用頁只影響介面，不影響 PDF）。
6. 調整請求書外觀：應用頁「明細」表格上方可選「明細表頭顏色」（5 色），此項會影響 PDF／列印，並隨草稿保存。
7. 返回首頁：應用頁 toolbar 點擊 **← 返回主頁**。
7. 印章產生器：點擊功能欄或首頁的 **🔏 印章產生器**（或印章上傳區的提示連結），前往 <https://sealkit.app/kaishain> 製作印章圖檔，下載後回到本頁「上傳」即可。
